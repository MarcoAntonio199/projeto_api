## PROJETO
Projeto que busca evoluir de acordo com os conhecimentos adquiridos com os estudos

Um microsserviço que permite:

Cadastrar serviços (ex: “corte de cabelo, 30 min”) e profissionais
Definir a disponibilidade de cada profissional
Clientes fazerem, consultarem e cancelarem agendamentos
Notificar sistemas externos quando algo muda (webhook/e-mail)

Stack: Node.js, TypeScript, PostgreSQL, Prisma, Jest, Docker. Você começa com Express ou Fastify e, no final, migra para NestJS.

Modelo básico: User (cliente, profissional, admin), Service, Availability, Booking
